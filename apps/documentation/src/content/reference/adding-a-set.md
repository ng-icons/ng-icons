---
title: Adding a new set
section: Icon sets
order: 15
lead: Icon sets are contributed by the community. If a set you use is missing, it can be added.
---

Open an issue on the repository describing the set, where it is published and the licence it carries. Sets need a licence that permits redistribution.

Once agreed, the set is generated from its source SVGs into a package of named constants, published as `@ng-icons/<set-name>` alongside the others.
